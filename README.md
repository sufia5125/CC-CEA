
# ArtWall 
A web-based print-on-demand artwork e-commerce site that helps users visualize and shop for premium art prints and originals.

## Features
* User authentication and registration
* Seamless cart and checkout using Stripe
* Artwork creation and updation for admins
* Responsive and user-friendly interface
## Tech Stack
* Frontend: React.js, Material UI
* Backend: Node.js, Express.js
* Database: MySQL

## Getting Started
### Prerequisites
* Node.js and npm installed
* install axios, MUI material/icons, jwtoken, bcrypt 
* MySQL instance 

## Installation

### 1. Install dependencies for both frontend and backend

```bash
cd backend
npm install

cd ../frontend
npm install
```

Set up environment variables as needed (see `sample.env` file).

---

## Running the Project

### Start the backend server

```bash
cd backend
npm start
```

### Start the frontend server

```bash
cd ../frontend
npm start
```
